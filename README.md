# SWAT: Tactical Response

A single-player, top-down 3D tactical SWAT game made in Unity. You lead a
small team of the (fictional) Port Avalon Police Department's Tactical
Response Unit: pick your officers and their kit at headquarters, read the
briefing, deploy by van, then clear buildings room by room, protect and
evacuate civilians, make suspects surrender, and get back to the extraction
point.

Everything (maps, characters, weapons, HQ, menus, sounds) is generated by code
at runtime from built-in Unity modules, so the project has no third-party
assets or package dependencies and runs on modest hardware.

> **Status:** prototype with ten levels, a level creator, a pixel-art look and a
> quality-of-life, graphics and lighting polish pass. The code compiles (checked outside the
> Unity editor, see [REPORT.md](REPORT.md#testing-performed)), the custom
> shaders pass a syntax check and the level creator's layout logic passes unit
> tests, but the game has **not yet been play-tested inside Unity**, no
> performance has been measured, and no gameplay screenshots exist yet.
> [Screenshots/README.md](Screenshots/README.md) explains how to capture them.

## Art style: pixel art (default) or smooth

The game now looks like a **pixel-art top-down game that is still 3D**: the
same 3D maps, characters and lights are drawn into a small low-resolution image
(about 320 game pixels tall) and scaled up with crisp, square pixels. The
camera is orthographic (no perspective) at the usual high angle, and it snaps
to whole game pixels so edges don't shimmer while it moves. On top of that:

- dark outlines around characters, furniture and walls (where the depth
  changes sharply),
- a reduced, ordered-dithered colour palette for the retro look,
- small point-filtered surface textures (16-32 px) and hard shadows,
- no anti-aliasing (it would blur the pixels).

The interface stays at full resolution, so text remains sharp.

**Settings -> Graphics:**

| Setting | Options |
| --- | --- |
| Art style | **Pixel art** (default) or **Smooth** (the previous full-resolution look with a perspective camera) |
| Pixel size | Chunky (about 240 px tall), **Medium** (about 320) or Fine (about 420) |
| Pixel outlines | On (default) / Off |

Pixel art is also cheap to draw, so it suits slow machines. Outlines and the
dithered palette are part of the Built-in pipeline's post pass; under URP the
pixel view and camera still work but those two effects are skipped (see
[REPORT.md](REPORT.md#part-0a-pixel-art-style)).

A **browser preview** of the style was made from the game's real level layouts
(rebuilt with three.js in a web page). It is an approximation for a feel of the
look, **not a Unity screenshot**, and it isn't part of the project.

## What's new: 10 levels, main menu and Level Creator

- **Ten numbered levels** plus Training, on nine different maps (six of
  them new: corner store, motel, bank, clinic, nightclub and steelworks).
  Levels unlock as you complete earlier ones; a level stays open once beaten.
- **Main menu hub:** Play/Continue (jumps to your next level), Level Select,
  Training, Level Creator, Officers, Equipment, Settings, Credits and Quit,
  with a ten-segment campaign progress bar and a preview of the next level.
- **Level Select:** a grid of all levels with thumbnails, level numbers,
  status, best score and difficulty, plus a details panel.
- **Level Creator:** build your own levels on a grid (rooms, doors, suspects,
  civilians, objectives, security devices and props), save them, and play
  them with your squad through the normal briefing and loadout screens. See
  [Level Creator](#level-creator) below.

## What's new in the polish update

## How to run

You need **Unity 6** (the project file targets `6000.0.23f1`; any 6000.0.x
should work). Install it through [Unity Hub](https://unity.com/download).
No extra packages are required.

1. Download this repository (GitHub: **Code -> Download ZIP**) and unzip it.
2. In Unity Hub, click **Add -> Add project from disk** and choose the unzipped folder.
   If Hub asks about the editor version, pick the Unity 6 version you have installed.
3. Wait for the first import. The editor script creates `Assets/Scenes/Boot.unity`
   and adds it to Build Settings the first time the project opens.
4. Open `Assets/Scenes/Boot.unity` (or any scene; the game starts itself) and press **Play**.
5. Click inside the Game view so it receives keyboard and mouse input.

If the Boot scene wasn't created, use the menu **SWAT -> Create Boot Scene**.
If nothing happens on Play, open **Window -> General -> Console** and look for red errors.

To build a standalone game: make sure `Boot.unity` is in **File -> Build Profiles / Build Settings**, then build.

## Game flow

**Main Menu -> Level Select -> Mission Briefing -> Officer Selection ->
Loadout -> Deployment (van arrival) -> Gameplay -> Debriefing -> Level Select**

(Custom levels: **Main Menu -> Level Creator -> Play -> Briefing -> ... ->
Debriefing -> Level Creator**.)

- **Main menu:** Play/Continue (next level), Level Select, Training, Level
  Creator, Officers, Equipment, Settings, Credits, Quit; campaign progress.
- **Level Select:** Training and Levels 1-10 with thumbnail, level number,
  difficulty, status and best score, and a button into the Level Creator.
- **Briefing:** situation, intel for this deployment, objectives (the random
  optional ones are shown), recommendations, difficulty and the random seed.
- **Officer selection:** six officers with portraits, roles, stats, abilities
  and preferred kit. Choose who you play as and up to three AI squadmates.
- **Loadout:** primary, sidearm, armor, shield, attachments, tactical
  equipment (limited by capacity) and uniform color, for each officer.
- **Debriefing:** result, rating, score breakdown, objectives, civilians,
  suspects, squad status, equipment used, unlocks; replay or return to HQ.

Start with **Training** (TRU Qualification Course): it walks through every
control step by step.

### Gamepad

A gamepad works when the project has Unity's **Input System** package
installed (Window -> Package Manager -> Input System, then allow the editor to
use the new input backend or "Both"). Without the package the game uses
keyboard and mouse only. Layout (Xbox names):

| Button | Action |
| --- | --- |
| Left stick / Right stick | Move / aim (also picks entries on radial menus) |
| RT / LT | Fire / steady aim |
| A / B / X / Y | Interact / crouch / reload / switch weapon (hold: weapon wheel) |
| LB (hold) / RB | Command wheel / use equipment |
| L3 / R3 | Sprint (toggle) / shout |
| D-pad up / down / left / right | Flashlight / role ability / previous / next equipment |
| Start / View | Pause / tactical map |

In menus the left stick moves the cursor and **A** clicks; the d-pad adjusts
sliders and **B** closes the settings window. Planning mode, fire mode, zoom
presets and selecting individual officers remain keyboard-only.

## How to play

- **Rules of engagement.** Shout first. Unarmed or surrendering suspects must
  be restrained (walk up and hold **E**), not shot. Shooting them, or hitting
  civilians, costs a lot of points. Arrests are worth more than force.
- **Doors.** Closed doors open with **E**. Locked doors: breaching charge (doors
  with yellow stripes), lock picking (some), a Breacher's kick (**T**), or a
  security console (electronic locks). Wedges (**G**) jam a door shut. The
  recon camera (**G** at a closed door) gives a partial look inside.
- **Squad.** Hold **Z** and point at a door to *Stack up*, *Open & clear*,
  *Breach & clear* or *Flash & clear*; point anywhere else to *Follow*, *Hold*,
  *Regroup*, *Move here*, *Cover area*, *Stay behind*, *Return to me*, *Assist
  civilians* or *Wait*. Squadmates shout compliance at suspects who aren't
  attacking and fire only at ones who are. Medics revive downed officers.
- **Civilians.** Press **E** to make a civilian follow you (or wait), treat the
  injured, free hostages, and lead them to the green **safe zone** or the blue
  **extraction** zone.
- **Information.** Rooms change on the tactical map as you discover,
  investigate and secure them. Threats appear only when your team can see
  them (plus their last known position). Security consoles can disable
  cameras, silence the alarm, unlock electronic doors and review footage.
- **Finishing.** When every primary objective is resolved, return to the
  extraction point. If the team leader goes down, the mission fails.

## Level Creator

Main menu -> **Level Creator** (or **Level Select -> Custom levels**). The
first time it opens, an example level ("Example: Pawn Shop") is created so you
can see how one is put together.

1. **Room** tool: drag rectangles on the grid (1 square = 1 metre). Pick the
   room type on the left (office, lobby, hallway, storage, security, vault,
   shop floor, club...); it sets the floor, lighting and sound. Rooms can't
   overlap; put them side by side and walls appear where they meet.
2. **Door** tool: click a wall to add a door (doors are two squares wide and
   need straight wall, away from corners). Click a door again to cycle its
   type: open doorway, door, locked (pick or breach), locked (breach only),
   electronic lock (opened from a security console).
3. **People**: Team Start (outside, the van parks to its right and drives in
   from behind), armed/unarmed/nervous suspects, guards, armored suspects, one
   leader, civilians, hostages, injured and hiding civilians. **R** turns them.
4. **Objectives**: extraction zone, safe zone, evidence, security console,
   camera, alarm panel.
5. **Props**: desks, tables, shelves, crates, couches, plants, counters,
   beds, cars and street lamps (most give cover).
6. Set the name, briefing text, time of day, difficulty, squad size, par time,
   ground and map size on the right. Objectives are generated from what you
   placed (secure suspects, arrest the leader, evacuate civilians, secure
   evidence, return to the van) and listed there.
7. Problems are listed on the right (no team start, rooms with no way in, no
   space for the van...). **Play level** saves and launches the level through
   the normal briefing, officer and loadout screens; the debriefing has a
   button back to the creator.

Controls: left click = use tool, right click = erase, mouse wheel = zoom,
middle-drag or WASD = pan, 1-7 = tools, R = turn, Delete = remove selection,
Ctrl+Z = undo, Ctrl+S = save, F = fit view, Esc = deselect / back.

Levels are saved as JSON files in `<persistentDataPath>/CustomLevels/`
(the folder is shown in **Open...**), so they can be copied and shared.
Custom levels keep a best score but don't count toward campaign unlocks.

## Runs on anything

Settings -> Graphics offers **Auto** (picks a preset from your hardware and
steps down if the frame rate stays under 40 FPS) or a fixed preset. Each
detail option can also be overridden individually, and **Performance Mode**
keeps the look but trims the expensive parts.

| Preset | What changes |
| --- | --- |
| Potato | 3D view at 50% resolution (interface stays sharp), no shadows, no real lights (light pools only), no AO or post-processing, low textures, fewer effects, AI updates less often |
| Low | 75% resolution, low hard shadows, no real lights, no AO, low textures |
| Medium | Full resolution, medium shadows, real fixture and flashlight lights, contact AO, post-processing (no bloom), medium textures |
| High | High soft shadows, 2x MSAA, bloom, high textures, VSync |
| Ultra | Very high shadows (soft flashlight shadow), 4x MSAA, more effects |

Light pools, emergency lighting, exit signs and dark-room shading are drawn on
every preset, so rooms keep their atmosphere even when real lights are off.

In the pixel-art style the resolution column doesn't apply: the 3D view is
always drawn at the pixel size you pick (Chunky, Medium or Fine), MSAA is off
and sun shadows are hard-edged. The other preset settings still apply.

## Editing content

Weapons, attachments, armor, equipment, officers, suspect types and missions
are ScriptableObject types (`WeaponData`, `OfficerData`, `MissionData`, ...).
The built-in versions live in `Scripts/Core/DefaultContent.cs`. Use
**SWAT -> Create Editable Data Assets** to write them out as assets under
`Assets/ScriptableObjects/*/Resources/SWAT/`; edit them in the Inspector and
the game uses your version (matched by `id`). New assets with new ids are
added too (missions also need a map id: `office`, `warehouse`, `apartment`, `training`, `store`, `motel`, `bank`, `clinic`, `nightclub` or `factory`).

Maps are built in code: `Scripts/Environment/OfficeMap.cs`, `WarehouseMap.cs`,
`ApartmentMap.cs`, `TrainingMap.cs`, `StoreMap.cs`, `MotelMap.cs`, `BankMap.cs`,
`ClinicMap.cs`, `NightclubMap.cs`, `FactoryMap.cs`, `HeadquartersMap.cs`, using
the helpers in `LevelBuilder.cs`. Levels made in the Level Creator are built by
`Scripts/LevelEditor/CustomLevelBuilder.cs` with the same helpers.
