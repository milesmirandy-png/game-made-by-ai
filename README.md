# SWAT: Tactical Response

A single-player, top-down 3D tactical SWAT game made in Unity. You lead a
small team of the (fictional) Port Avalon Police Department's Tactical
Response Unit: pick your officers and their kit at headquarters, read the
briefing, deploy by van, then clear buildings room by room, protect and
evacuate civilians, make suspects surrender, and get back to the extraction
point.

Everything (maps, characters, weapons, HQ, menus, sounds) is generated by code
at runtime from built-in Unity modules, so the project has no third-party
assets or package dependencies and runs on modest hardware.

> **Status:** prototype with a quality-of-life, graphics and lighting polish
> pass. The code compiles (checked outside the Unity editor, see
> [REPORT.md](REPORT.md#testing-performed)) and the custom shaders pass a
> syntax check, but the game has **not yet been play-tested inside Unity**,
> no performance has been measured, and no gameplay screenshots exist yet.
> [Screenshots/README.md](Screenshots/README.md) explains how to capture them.

## What's new in the polish update

- **Lighting:** Day, Evening and Night profiles per mission (choose on the
  briefing), interior light zones per room type with soft light pools under
  every fixture, flickering tubes, dark rooms during power cuts with emergency
  lights and exit signs, outdoor street lamps and fog. Shadows Off/Low/Medium/
  High/Very High, optional ambient occlusion (contact shading under walls and
  props) and a restrained post-processing pass (grading, vignette, bloom).
- **Environment:** tiling procedural materials (concrete, carpet, tile, brick,
  wood, metal, asphalt, grass), room identity (lobby, offices, security room,
  restrooms, break room, storage, hallways...), props such as filing
  cabinets, water coolers, fire extinguishers and alarms, electrical panels,
  monitors, vending machines, phones and ID badges; better doors with handles,
  frames, open/close/locked sounds and status text.
- **Characters and weapons:** helmets, vests with pouches and radios, gloves,
  boots and knee pads; squad ID colors and numbers (armband, marker, HUD);
  more varied suspects and civilians; blended walk/run/crouch/aim/reload
  animation, hit flinches, weapon sway, recoil, shell casings, surface impacts
  and bullet marks.
- **Quality of life:** weapon wheel (hold Q), auto reload, optional switch to
  sidearm when empty, low-ammo cue, unified interaction prompts with key caps,
  command wheel icons and order confirmation, radio callouts, objective
  banners, minimap, damage direction and edge feedback, camera smoothing,
  edge scrolling, auto indoor/outdoor zoom, screen-shake levels, mouse
  sensitivity and aim smoothing, crosshair options, van resupply.
- **Audio:** Master, Music, Weapons, Effects/environment, Voice/radio,
  Ambience and Interface volumes, indoor reverb by room, footsteps by floor
  surface, building hum, menu and mission music beds.
- **Settings:** Gameplay, Graphics (preset plus overrides for resolution,
  display mode, VSync, shadows, anti-aliasing, effects, textures,
  post-processing, ambient occlusion, view distance, flashlight brightness and
  a Performance Mode), Audio, Accessibility (UI scale, text size, colorblind
  colors, subtitles and their size, screen shake, reduced flashes, crosshair)
  and Controls. Everything is saved.
- **Controller:** works when Unity's Input System package is installed (see
  below); prompts switch to gamepad buttons automatically.

## How to run

You need **Unity 6** (the project file targets `6000.0.23f1`; any 6000.0.x
should work). Install it through [Unity Hub](https://unity.com/download).
No extra packages are required.

1. Download this repository (GitHub: **Code -> Download ZIP**) and unzip it.
2. In Unity Hub, click **Add -> Add project from disk** and choose the unzipped folder.
   If Hub asks about the editor version, pick the Unity 6 version you have installed.
3. Wait for the first import. The editor script creates `Assets/Scenes/Boot.unity`
   and adds it to Build Settings the first time the project opens.
4. Open `Assets/Scenes/Boot.unity` (or any scene; the game starts itself) and press **Play**.
5. Click inside the Game view so it receives keyboard and mouse input.

If the Boot scene wasn't created, use the menu **SWAT -> Create Boot Scene**.
If nothing happens on Play, open **Window -> General -> Console** and look for red errors.

To build a standalone game: make sure `Boot.unity` is in **File -> Build Profiles / Build Settings**, then build.

## Game flow

**Main Menu -> Headquarters (mission board) -> Mission Briefing -> Officer
Selection -> Loadout -> Deployment (van arrival) -> Gameplay -> Debriefing ->
Headquarters**

- **Main menu:** Continue, New Mission, Mission Selection, Training, Officer
  Roster, Equipment, Settings, Credits, Quit.
- **Mission board:** five missions with thumbnail, type, difficulty, status and best score.
- **Briefing:** situation, intel for this deployment, objectives (the random
  optional ones are shown), recommendations, difficulty and the random seed.
- **Officer selection:** six officers with portraits, roles, stats, abilities
  and preferred kit. Choose who you play as and up to three AI squadmates.
- **Loadout:** primary, sidearm, armor, shield, attachments, tactical
  equipment (limited by capacity) and uniform color, for each officer.
- **Debriefing:** result, rating, score breakdown, objectives, civilians,
  suspects, squad status, equipment used, unlocks; replay or return to HQ.

Start with **Training** (TRU Qualification Course): it walks through every
control step by step.

### Gamepad

A gamepad works when the project has Unity's **Input System** package
installed (Window -> Package Manager -> Input System, then allow the editor to
use the new input backend or "Both"). Without the package the game uses
keyboard and mouse only. Layout (Xbox names):

| Button | Action |
| --- | --- |
| Left stick / Right stick | Move / aim (also picks entries on radial menus) |
| RT / LT | Fire / steady aim |
| A / B / X / Y | Interact / crouch / reload / switch weapon (hold: weapon wheel) |
| LB (hold) / RB | Command wheel / use equipment |
| L3 / R3 | Sprint (toggle) / shout |
| D-pad up / down / left / right | Flashlight / role ability / previous / next equipment |
| Start / View | Pause / tactical map |

In menus the left stick moves the cursor and **A** clicks; the d-pad adjusts
sliders and **B** closes the settings window. Planning mode, fire mode, zoom
presets and selecting individual officers remain keyboard-only.

## How to play

- **Rules of engagement.** Shout first. Unarmed or surrendering suspects must
  be restrained (walk up and hold **E**), not shot. Shooting them, or hitting
  civilians, costs a lot of points. Arrests are worth more than force.
- **Doors.** Closed doors open with **E**. Locked doors: breaching charge (doors
  with yellow stripes), lock picking (some), a Breacher's kick (**T**), or a
  security console (electronic locks). Wedges (**G**) jam a door shut. The
  recon camera (**G** at a closed door) gives a partial look inside.
- **Squad.** Hold **Z** and point at a door to *Stack up*, *Open & clear*,
  *Breach & clear* or *Flash & clear*; point anywhere else to *Follow*, *Hold*,
  *Regroup*, *Move here*, *Cover area*, *Stay behind*, *Return to me*, *Assist
  civilians* or *Wait*. Squadmates shout compliance at suspects who aren't
  attacking and fire only at ones who are. Medics revive downed officers.
- **Civilians.** Press **E** to make a civilian follow you (or wait), treat the
  injured, free hostages, and lead them to the green **safe zone** or the blue
  **extraction** zone.
- **Information.** Rooms change on the tactical map as you discover,
  investigate and secure them. Threats appear only when your team can see
  them (plus their last known position). Security consoles can disable
  cameras, silence the alarm, unlock electronic doors and review footage.
- **Finishing.** When every primary objective is resolved, return to the
  extraction point. If the team leader goes down, the mission fails.

## Runs on anything

Settings -> Graphics offers **Auto** (picks a preset from your hardware and
steps down if the frame rate stays under 40 FPS) or a fixed preset. Each
detail option can also be overridden individually, and **Performance Mode**
keeps the look but trims the expensive parts.

| Preset | What changes |
| --- | --- |
| Potato | 3D view at 50% resolution (interface stays sharp), no shadows, no real lights (light pools only), no AO or post-processing, low textures, fewer effects, AI updates less often |
| Low | 75% resolution, low hard shadows, no real lights, no AO, low textures |
| Medium | Full resolution, medium shadows, real fixture and flashlight lights, contact AO, post-processing (no bloom), medium textures |
| High | High soft shadows, 2x MSAA, bloom, high textures, VSync |
| Ultra | Very high shadows (soft flashlight shadow), 4x MSAA, more effects |

Light pools, emergency lighting, exit signs and dark-room shading are drawn on
every preset, so rooms keep their atmosphere even when real lights are off.

## Editing content

Weapons, attachments, armor, equipment, officers, suspect types and missions
are ScriptableObject types (`WeaponData`, `OfficerData`, `MissionData`, ...).
The built-in versions live in `Scripts/Core/DefaultContent.cs`. Use
**SWAT -> Create Editable Data Assets** to write them out as assets under
`Assets/ScriptableObjects/*/Resources/SWAT/`; edit them in the Inspector and
the game uses your version (matched by `id`). New assets with new ids are
added too (missions also need a map id: `office`, `warehouse`, `apartment` or `training`).

Maps are built in code: `Scripts/Environment/OfficeMap.cs`, `WarehouseMap.cs`,
`ApartmentMap.cs`, `TrainingMap.cs`, `HeadquartersMap.cs`, using the helpers
in `LevelBuilder.cs`.
