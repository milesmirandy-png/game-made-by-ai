# Screenshots

**No screenshots have been captured yet.** The game was written and
compile-checked without access to a running Unity editor, so there was no way
to take real Play Mode screenshots. Nothing in this folder is concept art or a
mockup; it is empty until someone captures the real game.

## How to capture them

1. Open the project in Unity 6 and press **Play** in `Assets/Scenes/Boot.unity`
   (see the main README). Set the Game view to a 16:9 resolution such as
   1920x1080 (Game view toolbar -> aspect dropdown).
2. Press **F12** at each moment below. The file is saved here, in
   `<project>/Screenshots/`, named `SWAT_<date>_<time>_<state>.png`.
   (The "Screenshot saved" message is delayed so it doesn't appear in the image.)
   In a built game, screenshots go to `<persistentDataPath>/Screenshots/`.
3. Any OS screen capture of the Game view also works.

| # | Required shot | How to get there |
| --- | --- | --- |
| 1 | Main menu | Press Play and wait on the title screen. |
| 2 | Officer selection and roster | Main menu -> **Officer Roster** (or Briefing -> *Select officers*). Click an officer card so the details and 3D preview show. |
| 3 | Weapon and equipment selection | Main menu -> **Equipment** (or Officers -> *Loadout*). Hover a weapon to show its stats. |
| 4 | Exterior building gameplay | **New Mission** (Operation Glass Desk) -> deploy -> after the van arrives, stand in the parking lot facing the entrance. |
| 5 | Interior office gameplay | Walk into the lobby or open office. |
| 6 | Player and squadmates near a door | Hold **Z**, point at a closed door, release on **Stack up**; wait until they report "In position", then capture with the wheel closed. |
| 7 | Squad command wheel | Hold **Z** with the cursor on a door and press **F12** while holding. |
| 8 | Civilian rescue | Find a civilian, press **E** ("Follow me"), and capture while they follow you toward the green safe zone. |
| 9 | Tactical map and planning mode | Press **Space** in a mission (select an officer and right-click to show a waypoint). |
| 10 | Mission debriefing | Finish or fail a mission (training is quickest) and capture the debriefing screen. |

Tip: use **Settings -> Graphics -> High/Ultra** for nicer shots, and turn
off the FPS counter (F10).
